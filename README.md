# ❌⭕ Tic Tac Toe (Morpion)

Jeu du **morpion** en Python, avec une interface graphique faite avec **Tkinter**.

## Fonctionnalités

- Mode 2 joueurs en local : les croix et les ronds jouent chacun leur tour
- Grille 3x3 dessinée avec un canvas Tkinter
- Détection automatique de la victoire

## Contrôles

| Action | Commande |
|---|---|
| Jouer une case | Clic gauche |
| Quitter | Bouton « Quitter » ou `Échap` |

## Installation

Pas de dépendance à installer, Tkinter est fourni avec Python.

```bash
python TicTacToe.py
```

## Technologies

- Python 3
- Tkinter
